# Security policy

Chiavora is pre-alpha and has not been audited. Do not use it for real
passwords yet.

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/MarkusNuo/chiavora/security/advisories/new),
not in a public issue. Say what you found, how to reproduce it and what an
attacker gains.

Everything in this repository is in scope. The threat model and its non-goals
are in [docs/security-design.md](docs/security-design.md) §1: a non-goal that
is not defended is not a vulnerability, a guarantee the code does not keep is.
